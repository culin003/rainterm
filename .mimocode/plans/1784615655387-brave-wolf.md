# Plan: Internationalization (i18n) Implementation

_Generated 2026-07-21 for Raindrop SSH Manager. Plan mode — no code edits until user approves._

## 1. Problem Statement

Raindrop SSH Manager currently has all UI strings hard-coded in Simplified Chinese. To support a broader user base and comply with modern software localization best practices, we need a JSON-based internationalization system supporting:
- **Simplified Chinese** (`zh_CN`) — default
- **Traditional Chinese** (`zh_TW`)
- **English** (`en_US`)

## 2. Solution Design

### 2.1 Core Component: `I18nManager`

**Package:** `com.raindrop.util`
**Pattern:** Singleton (eager initialization, thread-safe)

```java
public final class I18nManager {
    // Supported languages
    public static final String LANG_ZH_CN = "zh_CN";
    public static final String LANG_ZH_TW = "zh_TW";
    public static final String LANG_EN_US = "en_US";

    // Instance + state
    private static final I18nManager INSTANCE = new I18nManager();
    private final Map<String, String> messages = new ConcurrentHashMap<>();
    private String currentLang = LANG_ZH_CN;
    private final List<Runnable> languageChangeListeners = new CopyOnWriteArrayList<>();

    // Public API
    public static I18nManager getInstance() { return INSTANCE; }
    public String get(String key) { /* returns messages.getOrDefault(key, key) */ }
    public String get(String key, Object... args) { /* MessageFormat */ }
    public void setLanguage(String langCode) throws IOException { /* load + notify */ }
    public String getCurrentLanguage() { return currentLang; }
    public List<String> getSupportedLanguages() { /* return immutable list */ }
    public void addLanguageListener(Runnable listener) { /* register */ }
    public void removeLanguageListener(Runnable listener) { /* unregister */ }
}
```

**Key design decisions:**
- `ConcurrentHashMap` for thread-safe message lookup (UI thread + virtual threads)
- `CopyOnWriteArrayList` for listeners (rare writes, frequent reads)
- `get(key, args...)` uses `MessageFormat` for parameter substitution
- Fallback to key itself if translation missing (avoids NPE, visible marker)
- Resource path: `/i18n/messages_{lang}.json`

### 2.2 JSON Resource Format

**Location:** `src/main/resources/i18n/`
**Filename pattern:** `messages_{langCode}.json`

```json
{
  "common.ok": "确定",
  "common.cancel": "取消",
  "common.save": "保存",
  "common.delete": "删除",
  "common.connect": "连接",
  "common.disconnect": "断开",
  "common.error": "错误",
  "common.success": "成功",

  "main.title": "Raindrop SSH 管理器",
  "main.status.connected": "已连接",
  "main.status.disconnected": "已断开",

  "connection.name": "名称",
  "connection.host": "主机",
  "connection.port": "端口",
  "connection.username": "用户名",
  "connection.password": "密码",
  "connection.privateKey": "私钥",

  "settings.language": "语言",
  "settings.theme": "主题"
}
```

**Rules for keys:**
- Dot-separated hierarchy: `{section}.{item}`
- Lowercase + underscores, no spaces
- Common/shared strings under `common.*`
- View-specific strings under `{view}.*`
- Action verbs: `{context}.action.{verb}` (e.g. `connection.action.connect`)

### 2.3 Language Switching Flow

```
User selects language in Settings
  ↓
SettingsViewController → I18nManager.setLanguage(newLang)
  ↓
I18nManager loads /i18n/messages_{newLang}.json into ConcurrentHashMap
  ↓
I18nManager updates ConfigManager setting KEY_UI_LANGUAGE
  ↓
I18nManager notifies all registered Runnable listeners
  ↓
Each Controller updates its UI elements:
  - button.setText(i18n.get("common.ok"))
  - label.setText(i18n.get("connection.host"))
  ↓
TabManager + JediTermFX widgets may need re-creation (strings baked at init)
```

**ConfigManager integration:**
- New key: `KEY_UI_LANGUAGE = "ui.language"` (default: `zh_CN`)
- Persisted in `app_setting` table
- Loaded on startup via `I18nManager` constructor

### 2.4 Controller Integration Pattern

Each FXML controller must:
1. Call `I18nManager.getInstance()` in `initialize()`
2. Register a language-change listener
3. Extract all hard-coded strings to a `updateI18n()` method
4. Call `updateI18n()` from both `initialize()` and the listener

```java
public class MainController {
    @FXML private Label statusLabel;
    @FXML private Button connectBtn;

    private final I18nManager i18n = I18nManager.getInstance();

    @FXML
    public void initialize() {
        updateI18n();
        i18n.addLanguageListener(this::updateI18n);
    }

    private void updateI18n() {
        connectBtn.setText(i18n.get("common.connect"));
        statusLabel.setText(i18n.get("main.status.disconnected"));
    }
}
```

### 2.5 FXML Considerations

FXML files may have hard-coded `text="..."` attributes. Two options:
- **Option A (preferred):** Remove `text` from FXML, set in `updateI18n()` via controller
- **Option B:** Keep FXML defaults, let `updateI18n()` overwrite them

Recommendation: Option A — single source of truth in JSON, no duplication.

## 5. Risks & Mitigations

| Risk | Mitigation |
|------|------------|
| Some strings missed during controller migration | Grep project for Chinese characters / hard-coded English UI strings |
| JediTermFX widget has baked-in strings (search, copy, paste) | JediTermFX is locale-aware — check for its own i18n support; otherwise override context menu |
| JSON file malformed crashes startup | Wrap load in try/catch, fallback to previous language + show error toast |
| Traditional Chinese translation quality | Use professional translation; avoid Google Translate for technical terms |
