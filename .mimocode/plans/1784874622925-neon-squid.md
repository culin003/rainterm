# 标签页快捷键方案

## 需求概述

为标签页操作增加全局键盘快捷键，覆盖常用操作：复制标签、打开 SFTP、重新连接、切换到第 N 个标签页。

## 当前快捷键（已有）

| 快捷键 | 功能 |
|--------|------|
| `Ctrl/Cmd + N` | 新建连接 |
| `Ctrl/Cmd + W` | 关闭当前标签页 |
| `Ctrl + Tab` | 下一个标签页 |
| `Ctrl + Shift + Tab` | 上一个标签页 |
| `Ctrl/Cmd + Shift + D` | 断开所有连接 |
| `Ctrl/Cmd + ,` | 设置 |
| `Ctrl/Cmd + L` | 锁定 |

## 新增快捷键方案

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Ctrl/Cmd + Shift + T` | 复制标签页 | 用当前标签页的配置打开新 SSH 连接 |
| `Ctrl/Cmd + Shift + S` | 打开 SFTP | 为当前标签页的 SSH 会话打开 SFTP 标签页 |
| `Ctrl/Cmd + R` | 重新连接 | 断开并重连当前标签页 |
| `Ctrl/Cmd + 左右箭头` | 切换到左边/右边的标签页 | `Ctrl+←` 左边，`Ctrl+→` 右边 |
| `Ctrl/Cmd + 1~9` | 切换到第 N 个标签页 | 直接跳转（TabPane 原生支持此映射） |

## 修改文件

| 文件 | 改动 |
|------|------|
| `ui/MainController.java` | 在 `installAccelerators()` 中注册新快捷键 |

## 实现细节

### MainController.java

在 `installAccelerators()` 方法末尾追加：

```java
// 复制当前标签页
acc.put(new KeyCodeCombination(KeyCode.T, KeyCombination.SHORTCUT_DOWN, KeyCombination.SHIFT_DOWN),
    this::duplicateCurrentTab);

// 打开 SFTP（仅 SSH 标签页有效）
acc.put(new KeyCodeCombination(KeyCode.S, KeyCombination.SHORTCUT_DOWN, KeyCombination.SHIFT_DOWN),
    this::openSftpForCurrentTab);

// 重新连接当前标签页
acc.put(new KeyCodeCombination(KeyCode.R, KeyCombination.SHORTCUT_DOWN),
    this::reconnectCurrentTab);

// 切换到第 N 个标签页 (1-9)
for (int i = 1; i <= 9; i++) {
    final int index = i - 1;
    acc.put(new KeyCodeCombination(KeyCode.getKeyCode(String.valueOf(i)), KeyCombination.SHORTCUT_DOWN),
        () -> selectTab(index));
}
```

新增三个 private 方法：

```java
private void duplicateCurrentTab() {
    Tab current = tabPane.getSelectionModel().getSelectedItem();
    if (current == null) return;
    ConnectionProfile profile = tabManager.getTabProfile(current);
    if (profile != null) tabManager.openTab(profile);
}

private void openSftpForCurrentTab() {
    tabManager.openSftpForCurrentTab();
}

private void reconnectCurrentTab() {
    Tab current = tabPane.getSelectionModel().getSelectedItem();
    if (current == null) return;
    tabManager.reconnectTab(current);
}

private void selectTab(int index) {
    if (index < tabPane.getTabs().size()) {
        tabPane.getSelectionModel().select(index);
    }
}
```

### TabManager.java

需要暴露 `getTabProfile(Tab)` 方法（当前 `tabProfile` 是 private Map）：

```java
public ConnectionProfile getTabProfile(Tab tab) {
    return tabProfile.get(tab);
}
```

### 快捷键冲突处理

- `Ctrl/Cmd + R` 在 Windows/Linux 浏览器中是"刷新"，但在桌面 SSH 客户端中无此惯例，可安全使用。
- `Ctrl/Cmd + Shift + T` 在浏览器中是"重开已关闭标签"，与"复制当前标签"不冲突。
- `Ctrl/Cmd + 1~9` 是 TabPane 原生支持的数字切换模式，多个 IDE/终端都用此模式（iTerm2、Tabby 等）。
- 当应用锁定时，所有快捷键被 `installLockedKeySuppressor` 拦截，安全。

## 验证方式

1. `gradlew compileJava` 编译通过
2. 运行应用，测试：
   - `Ctrl/Cmd + Shift + T` 复制当前 SSH 标签页
   - `Ctrl/Cmd + Shift + S` 为已连接的 SSH 标签页打开 SFTP
   - `Ctrl/Cmd + R` 重新连接当前标签页
   - `Ctrl/Cmd + 1` 切换到第 1 个标签页
   - 锁定状态下按任意快捷键无效
3. 切换语言验证 i18n 正常
